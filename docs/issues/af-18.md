# AF-18: Deepgram voice picker and preview in dashboard settings

## Outcome

Choose a named Deepgram Aura-2 English voice in the dashboard when a Deepgram key is configured. Helena is the default for new configurations; existing saved choices remain unchanged. Other provider voice catalogs are deferred.

## Acceptance criteria

- [x] Settings display a named Deepgram voice dropdown with accent and feminine/masculine groups; saved model resolves to its name, including Helena, Hera, and Delia.
- [x] Without a Deepgram key, selection/preview are disabled and the UI explains how to enable them. Saving a key enables them; deleting it disables them without returning the key to the browser.
- [x] Saving a selected voice persists its exact Deepgram model across reload; STT and selected native session ID remain unchanged.
- [x] Preview uses the currently selected voice without saving it, making an agent turn, or changing provider configuration. Invalid preview model overrides are rejected before a provider call.
- [x] Closing settings or selecting another voice stops/discards the previous preview. Preview cannot overlap an active dashboard conversation. Provider failures are shown in settings without a false success notice.
- [x] Other providers retain their existing manual fields and do not show the Deepgram picker.
- [x] Playwright covers key gating, persistence, preview isolation/cancellation, and provider field switching. Unit/HTTP tests cover model validation and default/retained settings. One real Deepgram preview request succeeds.
