# AF-20: Configurable speech playback speed

GitHub tracker: [issue #20](https://github.com/nolanmak/Agentflow/issues/20).

Agentflow stores a nonsecret TTS playback rate from 0.75× through 2×. It applies the saved rate to browser replies and voice previews, and to macOS `afplay` for CLI/MCP speech. The MCP `speak` tool and CLI `--speed` flag can override the rate for one response without modifying saved preferences, agent context, provider selection, or synthesis requests.

Validation covers settings migration/defaulting, exact valid values, invalid-value rejection before provider access, browser preview/reply assignment, CLI/MCP request forwarding, and local player arguments. Live Deepgram/macOS 2× playback is recorded in [VALIDATION.md](../VALIDATION.md).
